# Misoki Botik

Telegram-бот для приёма заказов: запросы на стикеры и эмодзи, платные услуги, вопросы.
Заявки приходят обеим владелицам, ответить клиенту можно прямо из бота.

## Как это работает

1. Клиент жмёт `/start` и видит меню: **Запрос стикеров**, **Запрос эмодзи**, **Платные услуги**, **Задать вопрос**, **Перезагрузить меню**.
2. После выбора запроса клиент описывает заказ одним сообщением (текст, фото или файл).
3. Обе владелицы получают заявку с кнопками **💬 Ответить** и **✅ Готово**.
4. «Ответить» — владелица пишет сообщение, бот пересылает его клиенту. «Готово» — заявка закрыта.
5. Все заявки сохраняются в SQLite (`data/bot.db`).

## Переменные окружения

Копируешь `.env.example` в `.env` и заполняешь:

| Переменная | Обязательна | Что это |
|---|---|---|
| `BOT_TOKEN` | да | токен от [@BotFather](https://t.me/BotFather) |
| `OWNER_IDS` | да | числовые Telegram ID обеих владелиц через запятую, например `111,222` (узнать у [@userinfobot](https://t.me/userinfobot)) |
| `OWNER_USERNAMES` | нет | юзернеймы владелиц без `@` через запятую — показываются в «Платных услугах» |
| `DB_PATH` | нет | путь к файлу базы, по умолчанию `data/bot.db` |

> ⚠️ Каждая владелица должна один раз нажать `/start` у бота, иначе Telegram не даст боту писать ей.
> Токен никогда не коммитим — файл `.env` в `.gitignore`.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env             # и заполни значения
python main.py                   # то же самое: python -m bot.main
```

## Структура

```
bot/
  main.py        запуск бота
  config.py      чтение .env
  db.py          SQLite (таблица requests)
  keyboards.py   кнопки меню
  texts.py       все тексты (правятся здесь)
  handlers/
    user.py      меню и приём заявок
    owner.py     ответы владелиц и «Готово»
```

## Как добавить кнопку

В `bot/keyboards.py` добавь `kb.button(text="...", callback_data="menu:что-то")`,
затем обработчик в `bot/handlers/user.py` (по образцу `menu:paid`).
