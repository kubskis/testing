# Misoki Botik

Telegram-бот для приёма заказов: запросы на стикеры и эмодзи, платные услуги, вопросы.
Заявки приходят обеим владелицам, ответить клиенту можно прямо из бота.

## Как это работает

1. Клиент жмёт `/start` — бот присылает приветствие (с фото, если оно загружено) и показывает **постоянную клавиатуру под полем ввода**: **Запрос стикеров**, **Запрос эмодзи**, **Платные услуги**, **Задать вопрос**, **Перезагрузить меню**.
2. Стикеры и эмодзи — **анкета по шагам** (бот задаёт вопросы по очереди), в конце клиент присылает 3+ фото персонажа и отправляет анкету.
   - Стикеры: имя | фандом → с анимацией/без → с колором/без → количество → юз для связи → пожелания.
   - Эмодзи: имя | фандом → с колором/без → количество → с обводкой/без → юз для связи → пожелания.
   - «Юз для связи» и «Пожелания» можно пропустить: бот сам подставит юзернейм клиента (или имя, если юзернейма нет).
   - Бесплатно до 40 шт., сверх — доплата 15⭐/15₽ за каждые +10. Лимиты: стикеры 120, анимированные 50, эмодзи 120.
3. У каждой заявки свой **номер** (#1, #2, …). Владелицам заявка приходит **одним альбомом: фото с текстом заявки в подписи**, а сразу под ним — короткое сообщение с кнопками (Telegram не умеет крепить кнопки к альбому):
   **✅ Принять** · **❌ Отклонить** · **💬 Написать клиенту**.
   - «Принять» — клиенту приходит «ты в очереди, место №N». Дальше кнопка **✅ Выполнено** уведомляет клиента, что заказ готов.
   - «Отклонить» — бот спросит причину; отправь `-`, чтобы отказать без причины.
   - Статус обновляется у обеих владелиц, двойное нажатие невозможно.
4. **Одна открытая заявка каждого типа на человека** (1 на стикеры, 1 на эмодзи, 1 вопрос). Новую можно подать после того, как прежняя выполнена или отклонена.
5. «Задать вопрос» — вопрос текстом; владелица отвечает кнопкой **💬 Ответить** (это закрывает вопрос) или закрывает/отклоняет его.
6. Команда `/queue` (только для владелиц) — список открытых заявок.
7. Кнопка «Меню» рядом с полем ввода открывает список команд (`/start`, `/cancel`, у владелиц ещё `/queue` и `/setwelcome`).
   **Админ-панель:** владелицы видят в меню кнопку «Админ-панель» (или команда `/admin`). Там можно изменить текст приветствия, анкеты на стикеры, анкеты на эмодзи и платных услуг, а также вернуть стандартный текст. Форматирование Telegram (жирный, курсив) и премиум-эмодзи сохраняются: достаточно вставить их в сообщение с новым текстом, искать ID не нужно. Если Telegram не примет текст, бот оставит прежний.
   **Фото для приветствия:** владелица присылает боту фото с подписью `/setwelcome` (или отвечает этой командой на фото). Убрать — `/clearwelcome`.
8. Кнопки цветные (синие, зелёные, красные) — цвета задаются в `bot/keyboards.py`. Для этого нужен aiogram 3.31+.
9. Все заявки хранятся в SQLite (`data/bot.db`).

## Переменные окружения

Копируешь `.env.example` в `.env` и заполняешь:

| Переменная | Обязательна | Что это |
|---|---|---|
| `BOT_TOKEN` | да | токен от [@BotFather](https://t.me/BotFather) |
| `OWNER_IDS` | да | числовые Telegram ID обеих владелиц через запятую, например `111,222` (узнать у [@userinfobot](https://t.me/userinfobot)) |
| `OWNER_USERNAMES` | нет | юзернеймы владелиц без `@` через запятую — показываются в «Платных услугах» |
| `DB_PATH` | нет | путь к файлу базы, по умолчанию `data/bot.db` |

> ⚠️ Каждая владелица должна один раз нажать `/start` у бота, иначе Telegram не даст боту писать ей.
> Токен никогда не коммитим — файл `.env` в `.gitignore`.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env             # и заполни значения
python main.py                   # то же самое: python -m bot.main
```

## Структура

```
assets/
  stickers_banner.jpg  картинка к анкете на стикеры
  emoji_banner.jpg     картинка к анкете на эмодзи
  (чтобы поменять картинку, замени файл с тем же именем)
bot/
  main.py        запуск бота
  config.py      чтение .env
  db.py          SQLite (заявки, статусы, лимит «1 открытая на тип»)
  forms.py       анкеты: вопросы, лимиты, цены (правятся здесь)
  texts.py       стандартные тексты (владелицы могут менять их в админ-панели)
  content.py     тексты, изменённые через админ-панель
  render.py      текст заявки для владелиц
  keyboards.py   кнопки
  services.py    отправка заявок владелицам и уведомления клиентам
  handlers/
    user.py      меню, анкета по шагам, отправка заявки
    admin.py     админ-панель: смена текстов
    owner.py     принять / отклонить / выполнено / написать клиенту, /queue
```

## Как добавить кнопку

В `bot/texts.py` добавь название кнопки (`BTN_...`), в `bot/keyboards.py` — саму кнопку в `main_reply_kb()`,
затем обработчик `@router.message(F.text == texts.BTN_...)` в `bot/handlers/user.py` (по образцу `BTN_PAID`).
